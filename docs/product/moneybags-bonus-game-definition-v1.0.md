# Moneybags Bonus game definition v1.0

Status: **JAX PRODUCT ACCEPTANCE — APPROVED**  
Implementation stage: **PLAYABLE PROTOTYPE**  
Release authority: **Not approved**

## Approved game job

| Field | JAX-approved definition |
|---|---|
| Player | A child, adult or other approved family member playing within the authorised Family Guardian household/session. |
| Purpose | Celebrate a verified, family-approved budget or savings achievement with a short, high-energy Moneybags experience without exposing private financial data. |
| Core loop | Moneybags animates and fires coins from his bag/head area. The player taps moving coins for **+50 game-score points**, builds combos and fills the Moneybags Bonus meter. Rare approved bonus objects may increase round score. |
| Win | Complete the round and reach the configured Moneybags Bonus target before time expires. |
| Finish without target | The timer expires and the round ends with the achieved score and an encouraging result. There is no punishment or loss of Family Points, money or previously earned rewards. |
| Session | 60-second target, configurable from 45–120 seconds for testing and accessibility. |
| Reward | Immediate animation, score, celebration, cosmetic/progression results and approved game unlocks. Actual Family Points or real-family rewards require separate Core and adult reward authority. |
| Family value | Reinforce shared budget/savings wins and create a positive family celebration without making children financial decision-makers. |
| Out of scope | Banking transactions or credentials, cards, investments, financial advice, child-controlled spending, wagering, simulated betting, purchased chance mechanics, loot boxes, cash prizes, automatic Family Points creation, household financial records, or bypassing adult/Core authority. |

## Non-negotiable authority wall

Game score is not Family Points. A coin tap adds exactly **+50 game score** and
does not create, transfer, redeem or promise Family Points. Eligibility is not
unlock authority. Any consequential reward requires the existing adult/Core
authority path and must fail safely when that authority is absent or invalid.

The local prototype uses an explicitly simulated, adult-approved demo unlock and
awards zero Family Points.

## Moneybags character lock

Do not redesign Moneybags. Approved future character assets may add idle, grin,
laugh, coin-burst, larger-combo, dance/celebration and round-complete animation
states while preserving the approved character direction and visual identity.

The current prototype uses a clearly labelled placeholder representation until
approved Moneybags artwork is supplied.

## Approved sequence

Moneybags opens → coins erupt → tap coin → +50 game score → feedback → combo
climbs → intensity rises → Moneybags reacts → target fills → family celebration.
